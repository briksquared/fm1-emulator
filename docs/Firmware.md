# Firmware

## Switching firmware
Pick a firmware from the dropdown and press **Start**. 115 open-source firmwares are built in and
run offline. You can deep-link one by adding `?fw=<id>` to the address (ids match the catalog).

## Loading your own
Drag any `.fwsc` file onto the window to run it — useful for firmware that isn't bundled (the
M-VAVE stock firmware, betas, or your own builds). Maximum file size is 8 MB.

## Where to find more
Community firmware lives on hubs such as [the FM-1 Firmware Hub](https://thefirmwarehub.com/) and
[fm1-editor.com](https://fm1-editor.com/firmware/), and on each author's GitHub. Download the
`.fwsc` and drop it in.

## Why isn't a particular firmware included?
Only firmwares with a clear open-source license are bundled. Anything unlicensed or proprietary
is left out of the download — but you can still load it yourself with drag-and-drop.
